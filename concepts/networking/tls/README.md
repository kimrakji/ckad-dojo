# TLS: 프로토콜 협상과 인증서 검증

TLS는 클라이언트와 서버 사이의 통신을 보호하는 프로토콜입니다. HTTPS는 TLS 연결 위에서 HTTP 요청과 응답을 주고받습니다. 이 문서는 허용 버전, 서버 인증서, 실제 접속 검증을 구분하여 설명합니다.

## Handshake: 연결 수립

클라이언트와 서버는 함께 사용할 수 있는 TLS 버전과 암호화 구성을 협상합니다. 서버는 인증서를 제시하고, 클라이언트는 신뢰 여부와 접속한 호스트 이름을 확인합니다. 연결 수립이 실패하면 HTTP 요청·응답 단계까지 진행하지 못합니다.

예를 들어 서버가 TLS 1.3만 허용하고 클라이언트가 TLS 1.2만 사용한다면 함께 사용할 버전이 없습니다. 서버가 TLS 1.2와 TLS 1.3을 모두 허용하면 두 버전으로 각각 연결을 시도할 수 있습니다.

## Certificate: 서버 인증서

| 항목 | 역할 |
| --- | --- |
| 인증서 | 서버의 공개 키와 이름 등 정보를 담으며 발급자의 서명이 포함됨 |
| 개인 키 | 인증서의 공개 키와 대응하며 서버가 보관하여 사용 |
| 신뢰할 인증서 | 클라이언트가 서버 인증서를 검증할 때 사용할 신뢰 기준 |
| Subject Alternative Name | 인증서가 유효한 DNS 이름이나 IP 주소 |

자체 서명 인증서는 기본 신뢰 목록에 없을 수 있습니다. 실습에서는 생성한 인증서를 명시적으로 신뢰하도록 지정하거나 인증서 검증을 생략하여 프로토콜 동작을 비교할 수 있습니다. [OpenSSL 인증서 생성과 확장](https://docs.openssl.org/3.0/man1/openssl-req/)

## Protocol Settings: 허용 버전 설정

허용할 버전은 TLS를 처리하는 서버에서 설정합니다. 예를 들어 Nginx의 `ssl_protocols TLSv1.2 TLSv1.3;`는 두 프로토콜을 허용합니다. [Nginx ssl_protocols](https://nginx.org/en/docs/http/ngx_http_ssl_module.html#ssl_protocols)

인증서 파일을 전달하는 작업과 서버의 허용 버전을 지정하는 작업은 별개입니다. 설정 변경을 서버가 언제 다시 읽는지도 사용한 서버의 동작에 따라 확인해야 합니다.

## Curl Options: 요청 옵션

| 옵션 | 역할 |
| --- | --- |
| `--tlsv1.2` | 사용할 TLS 버전의 최솟값을 1.2로 지정 |
| `--tls-max 1.2` | 최댓값을 1.2로 지정하여 위 옵션과 함께 TLS 1.2로 한정 |
| `--tlsv1.3 --tls-max 1.3` | TLS 1.3으로 한정 |
| `--cacert <file>` | 서버 인증서 검증에 사용할 신뢰할 인증서 파일 지정 |
| `-k` / `--insecure` | 서버 인증서의 신뢰 및 이름 검증 생략 |
| `--resolve host:port:address` | URL의 호스트를 유지하면서 지정 주소로 접속 |
| `--fail` | HTTP 400 이상 응답도 실패로 처리 |

`--tlsv1.2`만 지정하면 TLS 1.3으로도 연결할 수 있으므로 TLS 1.2 허용 여부를 입증하려면 최댓값을 함께 지정합니다. `-k`는 인증서 검증을 생략하지만 프로토콜 불일치를 해결하지는 않습니다. TLS 연결과 암호화는 그대로 수행됩니다. [curl 공식 매뉴얼](https://curl.se/docs/manpage.html)

## Diagnosis: 실패한 단계 찾기

| 관찰 결과 | 확인할 내용 |
| --- | --- |
| 이름을 찾지 못함 | DNS 또는 `--resolve`의 호스트·포트 |
| TCP 연결 거부 | 서버 실행 여부, 주소와 포트 |
| 한 TLS 버전만 실패 | 서버 허용 버전과 클라이언트의 TLS 지원 |
| 인증서 검증 실패 | 발급자 신뢰, 유효 기간, 접속 이름과 인증서 이름 |
| HTTPS 연결 후 HTTP 오류 | 애플리케이션 응답 |

오류 문구는 TLS 구현과 버전에 따라 달라질 수 있습니다. 같은 주소에 버전을 한정한 요청을 보내고 인증서 검증 결과를 함께 비교합니다.
